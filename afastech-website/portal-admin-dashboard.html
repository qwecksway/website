Individual transcript imports

Choose a PDF transcript. It is read in this browser only; the source file is never uploaded or saved. Extracted subject rows must be matched to an existing student, checked, and corrected before a private draft is saved. Letter grades and GPA are preserved as printed and are not converted to marks.

Review extracted records
