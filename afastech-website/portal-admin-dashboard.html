Register the SHS 3 student cohort

Paste or select the roster export with columns School Code, Name, CassRefID, LEARNING_AREA, YearOfEntry. Each student receives a unique generated password and signs in with their CassRefID. Passwords are not emailed or stored in the portal; download the credential file once and hand it out privately.
